# 一冊内の商品画像と元ファイル取得

ユーザーの「次へ」に基づきF15の小単位を実装。本棚の冊子間連携は再開しない。
- 既存商品一覧に「画像・素材」を追加。画像候補、型番との確認状態、表示用PNG、収録元ファイル、同冊子の使用箇所を表示。
- アップロード時の明示的preview関係のみ元ファイルと断定。同名のIDMLリンク素材は原本候補として要確認表示。欠落ファイルはダウンロード不可。
- 読取専用APIは販促/開発のみ。既存素材APIで強制ダウンロード指定を許可、既存の冊子/共有版権限を維持。
- 紙面/商品レビュー/DBスキーマは変更しない。読取版が違えば一覧更新を案内。
- 検証：候補/確定/再確認、素材欠落、別冊子非混入、閲覧権限、添付Content-Disposition、UI。
- F14改訂取込継承、F15の冊子横断/外部同期は今回の範囲外。
