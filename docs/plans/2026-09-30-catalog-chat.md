# カタログLLMチャット
ユーザー承認：固定質問・一覧ボタンを廃止し、LLMが都度読取ツールを選ぶ通常のチャットにする。
- 選択中の一冊、現在の権限のスナップショットを検索。商品条件/価格集計、詳細、掲載、画像、原稿質疑の5ツール。
- 外部OpenAI Responses API、store=false、サーバー環境変数。モデルは設定変更可能。質問と必要なツール結果のみ送る。画像バイナリは送らない。
- 会話はログインセッションと冊子に結びつけサーバーメモリで保持、版変更・ログイン変更・一定時間でリセット。書込ツール/任意SQL/外部URL取得はなし。
- 価格候補と確定・本体とセットを区別。数値条件・並び順・件数はPythonで処理。返却上限とデータ不足を伝える。
- 上限回数・応答サイズ・レート制限・同時実行制限。API失敗時に固定ルールへ偽装フォールバックしない。
- UIは会話/入力/送信/新しい会話。回答Markdownは限定レンダリングでHTMLを実行しない。根拠/素材リンクはツールが返した同冊子のもののみ。
- 検証：ツール条件、会話継続、版/権限分離、悪意ある出力、実LLMの2万円以下→安い順→画像。
リスク🟠：外部推論、会話混在、候補誤認、使用量。上記制限とテストで対策。
参考：https://developers.openai.com/api/docs/guides/function-calling
